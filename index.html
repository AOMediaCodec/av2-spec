About AV2

AV2 is the next-generation video codec from the Alliance for Open Media (AOM), designed to deliver significantly improved compression efficiency over AV1. This specification defines the bitstream syntax, semantics, and decoding process for AV2.

Notice
This specification is currently in draft status. We welcome feedback and issue reports via the GitHub issue tracker, though please note that responses may be limited as this is a work-in-progress document.

Using the Specification

Full Specification

The complete specification document includes all sections from scope and definitions through annexes. It provides comprehensive coverage of the AV2 codec format, syntax, semantics, and decoding process.

Syntax Browser

The syntax browser provides a specialized view of Sections 5 (Syntax Structures) and 6 (Semantics) in a split-pane interface. Features include:

  • Side-by-side view of syntax definitions and their semantics
  • Clickable syntax elements for easy navigation
  • Search functionality across both sections
  • Copy-to-clipboard for syntax structures

Attachments

The attachments directory contains extracted lookup tables from Section 9 as C header files, useful for implementation reference.

Reference Software

The reference software, known as AVM, corresponding to this version of the specification is research-v13.0.0 tag.
