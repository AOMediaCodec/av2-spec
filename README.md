# AV2 Specification

This repository contains the compiled **AV2 (Alliance for Open Media Video 2) Bitstream & Decoding Process Specification**.

## Contents

- `index.html` - The main specification document
- `syntax_browser.html` - Interactive syntax and semantics browser
- `images/`, `css/`, `js/` - Assets for the HTML specification
- `attachments/` - Header files containing lookup tables from Section 9
- PDF version (when available)

## Viewing the Specification

Open `index.html` in a web browser to view the specification. For the best experience, use a modern browser with JavaScript enabled.

The syntax browser provides a split-pane view of syntax structures (Section 5) and their semantics (Section 6) for easier navigation.

## About

This is a draft specification published by the Alliance for Open Media (AOM). The specification defines the bitstream format and decoding process for the AV2 video codec.

**Note**: This repository contains compiled outputs only. Issues may be submitted, but responses should not be expected.
